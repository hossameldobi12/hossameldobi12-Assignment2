What is SSH ? 

SSH (Secure Shell) is a protocol that lets you connect securely to a remote server over a network.

In GitHub, we use SSH to clone repositories and push or pull code without having to log in every time.

It uses two keys:
- Private Key : Stays on your computer. Never share it.
- Public Key  : You add it to your GitHub account.


In simple words : SSH makes working with GitHub more secure and convenient.
